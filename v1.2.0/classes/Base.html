    flyTo

    • flyTo(options: any): any

      相机飞行

      Parameters

      • options: any

        position（Cartesian3）：目标位置数组

        • distance（number）：距离
        • duration（number）：过度时长(秒为单位)
        • orientation：方位，包含[朝向|倾斜角|翻滚角]
        • easingFunction：飞行中在duration时间内插值方式
        • callback：操作完成后的回调

      Returns any

      Example

      import { Base } from 'cesium_dev_kit'
      const baseObj = new Base({
          cesiumGlobal: Cesium,
          containerId: 'cesiumContainer'
      })
      baseObj.base.flyTo({
      position: { x: -1337132.0092982147, y: 5330611.474631115, z: 3228680.029449292 },
      orientation: {
      heading: Cesium.Math.toRadians(1.0114629015290062),
      pitch: Cesium.Math.toRadians(-23.53661660731824),
      roll: Cesium.Math.toRadians(0.00324596311071617)
      },,
      distance：300,
      duration:3
      })

    pickUpPosition

    • pickUpPosition(e: any): any

      通过点击屏幕Cartesian2二维坐标，获取鼠标点击后的xy值； 根据xy判断当前目标对象是3dtiles、地形、模型、地球等通过不同方式获取对应位置信息

      Parameters

      • e: any

      Returns any

      Example

          cesiumGlobal: Cesium,
          containerId: 'cesiumContainer'
      })

        base.bindHandleEvent({
           leftClick: function click (event, _handlers) {
             const cartesian3 = base.pickUpPosition(event);
             console.log(cartesian3);
           }
          })
