    initThree

    • initThree(options?: ThreeInitOptions): threeObj

      初始化three

      参数

      • 可选options: ThreeInitOptions

        fov（number）：Camera frustum vertical field of view.（fusion 模式下由 Cesium 投影矩阵接管） 默认 45

        • aspect（number）：Camera frustum aspect ratio. 默认 window.innerWidth/window.innerHeight
        • near（number）：Camera frustum near plane.（fusion 模式下每帧跟随 Cesium frustum） 默认 1
        • far（number）：Camera frustum far plane.（fusion 模式下每帧跟随 Cesium frustum） 默认 10000000
        • center：Camera center coordinate. 默认 [104.081701757991, 30.627042558105988]
        • axesHelper：Enabled axes Helper. 默认 false
        • enableLighting：Enabled light. 默认 true
        • threeHabit：Enabled threejs Habit(Left click to modify pitch). 默认 true
        • fusion（'overlay'|'single-context'）：融合模式。 默认 'overlay'
        • depth（'none'|'canvas-blit'|'shader-copy'）：深度共享方式，仅 single-context 有效。
        • precision（'double'|'legacy'）：相机矩阵精度策略。 默认 'double'
          • overlay：双 Canvas 叠加（历史行为，零耦合）
          • single-context：three 复用 Cesium 的 canvas 与 WebGL 上下文，绘制挂在 scene.postRender 默认 canvas-blit：把 Cesium 离屏 FBO 的深度 blit 到画布深度缓冲，从而实现相互遮挡。 shader-copy 为预留值（当前回退到 canvas-blit），none 表示只共享上下文、不共享深度。 double 复制 Cesium 投影矩阵并在 float64 里合成视图矩阵；legacy 为历史行为。

      返回 threeObj

      示例

      import { ThreeJs } from 'cesium_dev_kit/three'
      const threeObj = new ThreeJs({
          cesiumGlobal: Cesium,
          threeGlobal: THREE,
          containerId: 'cesiumContainer',
          threeContainerId: 'threeContainer',
        })
        const { scene, camera } = threeObj.threeJs.initThree({
          center,
          fusion: 'single-context',
          depth: 'canvas-blit'
        });

    setPosition

    • setPosition(object?: ThreeObject3D, position?: number[]): any

      设置 three 对象(模型/网格等)在地球上显示的位置 【注意】需要先调用 initThree 并且对象已通过 scene.add 添加到场景

      参数

      • 可选object: ThreeObject3D

        three 对象（THREE.Object3D）

      • 可选position: number[]

        lng, lat, height 或 Cesium.Cartesian3/Cartographic

      返回 any

      示例

      const { scene, camera } = threeObj.threeJs.initThree({ center });
      const loader = new GLTFLoader();
      loader.load('model.glb', (gltf) => {
        scene.add(gltf.scene);
        threeObj.threeJs.setPosition(gltf.scene, [104.081701757991, 30.627042558105988, 0]);
      })
