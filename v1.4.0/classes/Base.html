    bindHandleEvent

    • bindHandleEvent(options?: BindHandleEventOptions): any

      鼠标事件注册

      参数

      • options: BindHandleEventOptions = {}

        leftClick：左键点击，回调签名 (event, handlers)

        • mouseMove：鼠标移动
        • doubleClick：左键双击
        • leftDown：左键按下
        • mouseWheel：鼠标滚动

      示例

          Cesium,
          containerId: 'cesiumContainer'
      })
       base.bindHandleEvent({
      leftClick: function click(event, _handlers) {
      todo something...
      },
      mouseMove: function move(event) {
      todo something...
      },
      });

    flyTo

    • flyTo(options?: CameraSetOptions): any

      相机飞行

      参数

      • 可选options: CameraSetOptions

        position（Cartesian3）：目标位置数组

        • distance（number）：距离
        • duration（number）：过度时长(秒为单位)
        • orientation：方位，包含[朝向|倾斜角|翻滚角]
        • easingFunction：飞行中在duration时间内插值方式
        • callback：操作完成后的回调

      返回 any

      示例

      import { createKit } from 'cesium_dev_kit'
      const kit = createKit({
          Cesium,
          containerId: 'cesiumContainer'
      })
      kit.base.flyTo({
      position: { x: -1337132.0092982147, y: 5330611.474631115, z: 3228680.029449292 },
      orientation: {
      heading: Cesium.Math.toRadians(1.0114629015290062),
      pitch: Cesium.Math.toRadians(-23.53661660731824),
      roll: Cesium.Math.toRadians(0.00324596311071617)
      },,
      distance：300,
      duration:3
      })

    getHandlerClickPosition

    • getHandlerClickPosition(e: ScreenSpaceEventMovement): any

      获取鼠标点击后的位置信息

      参数

      • e: ScreenSpaceEventMovement

        监听的事件对象

        • position（Cartesian2）：事件发生时的屏幕二维坐标（像素）
        • endPosition（Cartesian2）：鼠标移动时的结束位置，仅 MOUSE_MOVE 事件有

      返回 any

      示例

      import { createKit } from 'cesium_dev_kit'
      const { base } = createKit({
          Cesium,
          containerId: 'cesiumContainer'
      })

        base.bindHandleEvent({
           leftClick: function click (event, _handlers) {
             const { wgs84Coor, graphicCoor, cameraPosition } = base.getHandlerClickPosition(event);
             console.log(wgs84Coor, graphicCoor, cameraPosition);
           }
          })

    pickUpPosition

    • pickUpPosition(e: ScreenSpaceEventMovement): any

      通过点击屏幕Cartesian2二维坐标，获取鼠标点击后的xy值； 根据xy判断当前目标对象是3dtiles、地形、模型、地球等通过不同方式获取对应位置信息

      参数

      • e: ScreenSpaceEventMovement

        监听的事件对象

        • position（Cartesian2）：事件发生时的屏幕二维坐标（像素）
        • endPosition（Cartesian2）：鼠标移动时的结束位置，仅 MOUSE_MOVE 事件有

      返回 any

      示例

      import { createKit } from 'cesium_dev_kit'
      const { base } = createKit({
          Cesium,
          containerId: 'cesiumContainer'
      })

        base.bindHandleEvent({
           leftClick: function click (event, _handlers) {
             const cartesian3 = base.pickUpPosition(event);
             console.log(cartesian3);
           }
          })
