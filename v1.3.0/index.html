    cesium_dev_kit - v1.3.0

    cesium_dev_kit

    Cesium 开发套件：标绘、量算、分析、自定义材质 / 图元、传感器、热力图、后处理特效、Three.js 集成，以及地形编辑（开挖 / 堆高）。

    A Cesium development kit: plotting, measurement, analysis, custom materials / primitives, sensors, heatmap, post-processing effects, Three.js integration and terrain editing.

    在线 Demo：https://dengxiaoning.github.io/cesium_dev_kit/demo/?auto=1

    左侧目录里的每一个类，在 Demo 里都有对应的示例页面（标绘、量算、分析、材质、后处理、 路径漫游……），页面左侧菜单按同样的分类排列，可以直接点开看效果，也可以对照着抄代码。 演示站用模拟账号自动登录（?auto=1），无需注册。想本地跑：npm run dev。

    安装

    npm install cesium_dev_kit cesium
    # 可选：仅 Three.js 集成需要
    npm install three

    需要 Cesium >=1.105。three、echarts、dat.gui、libgif 均为可选 peer 依赖， 只在使用对应能力时才需要安装。

    Cesium 静态资源（必读）

    本套件不包含 Cesium 自身的运行资源。首次渲染前，Assets/、Workers/、ThirdParty/ 和 Widgets/widgets.css 必须可访问，否则会出现地球不显示、瓦片加载失败、控件无样式。

    • Vite：npm i -D vite-plugin-cesium，然后在 vite.config.ts 里 plugins: [cesium()]。
    • 手动：把 node_modules/cesium/Build/Cesium/{Assets,Workers,ThirdParty,Widgets} 拷到 public/cesium/，引入 Cesium 之前设置 window.CESIUM_BASE_URL = '/cesium/'，并 import 'cesium/Build/Cesium/Widgets/widgets.css'。
    • 容器必须有明确高度（width/height: 100%），否则画布高度为 0。
    • 记得设置 Cesium.Ion.defaultAccessToken。

    快速开始

    import * as Cesium from 'cesium'
    import { createKit } from 'cesium_dev_kit'

    const kit = createKit({
      Cesium,
      containerId: 'cesiumContainer',
      assetsBaseUrl: '/static/'
    })

    // 点
    kit.graphics.getPointGraphics({ color: Cesium.Color.GREEN, pixelSize: 6 })

    // 面（坐标直接给 Cartesian3）
    kit.graphics.createPolygonGraphics({
      positions: Cesium.Cartesian3.fromDegreesArray([104.09, 30.65, 104.11, 30.65, 104.10, 30.63]),
      material: Cesium.Color.RED.withAlpha(0.3),
      clampToGround: true
    })

    // 页面卸载时释放（幂等；kit 自己创建的 viewer 才会被 destroy）
    kit.dispose()

    也可以按需单独实例化（每个实例持有自己的 Cesium 闭包，同一页面多个 viewer 互不干扰）：

    import { Graphics } from 'cesium_dev_kit/graphics'

    const graphics = new Graphics({ Cesium, viewer })
    graphics.createLineGraphics({ positions: [[104.09, 30.65], [104.11, 30.68]], width: 3 })

    可用子路径：/graphics、/material、/primitive、/draw、/analysis、/plugin、 /pass-effect、/control、/three、/custom-cesium-plugin、/default-static。

    地形编辑需要在 createKit 里传入 three，并先 initThree：

    import * as THREE from 'three'

    const kit = createKit({ Cesium, three: THREE, containerId: 'cesiumContainer' })
    const { scene } = kit.threeJs.initThree({ center: [117.1, 36.25] })
    kit.threeJs.loop(() => scene.update())

    // ① 笔刷用法：铺一块可编辑区域，按住左键持续开挖
    await kit.terrainEdit.setArea([117.1, 36.25], { size: 2400, segments: 160 })
    kit.terrainEdit
      // maxDelta 是「一级台阶的落差」：每次落笔把笔刷核心压到同一个绝对标高，
      // 单笔就是「平底平台 + 窄直壁 + 两道硬坡折」，而不是一个光滑的碗。
      // 拖动时整条笔画锁定该标高，沟底是水平的；指针停住才按节拍逐级下挖。
      // 默认参数已经调好，无需额外开关：strength 1 / hardness 0.9 / roughness 0.28
      .setBrush({ mode: 'lower', radius: 110, maxDelta: 3 })
      .enableBrush(true)   // 按住左键持续开挖，右键转视角，滚轮缩放

    // ② 多边形用法：一次成型，可带台阶 / 水面
    await kit.terrainEdit.setPolygon([[117.095, 36.245], [117.105, 36.245], [117.105, 36.255], [117.095, 36.255]])
    kit.terrainEdit.apply({ mode: 'sink', depth: 60, stepHeight: 6, waterLevel: 0.3 })
    console.log(kit.terrainEdit.getStats())

    地表纹理直接取自当前影像图层（buildImageryTexture），所以挖开的地表仍然是它原本的 卫星影像，而不是一块纯色网格；等高线按固定等高距用 marching squares 生成。

    保存与二次编辑

    库不替你决定数据存到哪儿，只负责给出一份完整、可序列化的结果；落库、落盘、 发后端由业务侧决定：

    // 导出：一次拿到「原始 + 编辑后」两份高度场、多边形、水面与笔刷设置
    const data = kit.terrainEdit.exportData()!   // 尚未圈定范围时返回 null
    await fetch('/api/terrain/42', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data)                 // 纯 JSON，无 TypedArray / 无类实例
    })

    // 载入：不会再采样地形，直接复原成可继续编辑的状态（换设备、地形服务变了也一样）
    const saved = await (await fetch('/api/terrain/42')).json()
    kit.terrainEdit.importData(saved).enableBrush(true)

    // 只要数值、不需要序列化时用它：数组是副本，差值是挖填量（负数挖、正数填）
    const field = kit.terrainEdit.getHeightField()!
    const delta = field.current.map((h, i) => h - field.base[i])

    为什么不是内置一个 save() 写文件：编辑数据可能要进业务库、要带用户与权限、 要压缩加密、要转换成 GIS 格式，这些决定都不属于渲染库。exportData() 返回的 结构稳定（带 kind 与 version），你可以原样存，也可以只取 grid.current 自己转格式。 体量参考：segments = 160 约 277KB（两份 161×161 Float32，base64 后），gzip 约 180KB。 体量是被「无损」撑起来的：需要更小就降低 segments，或用 getHeightField() 自己转成 Int16 量化 / GeoTIFF 之类的格式。

    方法签名的参数对象（如 PointGraphicsOptions）在方法页里已经展开成字段表， 不用再点进类型页；craeteXxx 这类旧拼写的别名已从文档隐藏，请改用 createXxx。

    错误处理与生命周期

    import { createKit, isCesiumDevKitError, setErrorHandler } from 'cesium_dev_kit'

    // 统一捕获库内抛出的错误（带稳定 code，便于上报与用户提示）
    setErrorHandler((err) => {
      if (isCesiumDevKitError(err)) console.warn(err.code, err.message)
    })

    const kit = createKit({ Cesium, containerId: 'cesiumContainer' })
    kit.dispose() // 释放监听器 / DataSource；外部传入的 viewer 不会被销毁
