    drawCircleGraphics

    • drawCircleGraphics(options?: DrawOptions): void

      画圆

      Parameters

      • Optionaloptions: DrawOptions

        style（PolylineStyleType）：图形样式（Cesium 实体属性子集：width / material / clampToGround / granularity / arcType 等）；不传时各方法自带默认样式

        • callback（(...args: any[]) => void）：绘制完成回调。回调参数随方法不同：画线/画矩形为 (positions, entity)，画圆为 ({ center, radius }, entity)
        • measure（boolean）：是否开启量算：画线时实时测距、画面时实时测面积
        • width（number）：宽度（米）：画走廊时的走廊宽度，默认 100
        • height（number）：高度（米）：画矩形的挤出高度、画走廊时的走廊高度，默认 1
        • material：材质，覆盖 style.material
        • clampToGround（boolean）：是否贴地
        • clampToS3M（boolean）：是否贴合 S3M 倾斜模型表面
        • granularity（number）：采样粒度（弧度），默认 Cesium.Math.RADIANS_PER_DEGREE
        • arcType：线类型，默认 Cesium.ArcType.GEODESIC
        • type（string）：绘制子类型，如 straightLine 表示三点直线量测
        • topRadius（number）：圆柱 / 圆锥顶面半径（米）
        • bottomRadius（number）：圆柱 / 圆锥底面半径（米）
        • length（number）：圆柱 / 圆锥长度（米），不传时按绘制圆量出的半径推算
        • extrudedHeight（number）：挤出高度（米）
        • color：材质颜色，如画管道，默认 Cesium.Color.RED
        • rOuter（number）：星形截面外半径（像素），默认 150
        • rInner（number）：星形截面内半径（像素），默认 75
        • arms（number）：星形截面角数，默认 7
        • circleRadius（number）：圆形截面半径（像素），默认 20
        • shape（string）：管道截面形状：fivePoint 为五角星，其余为圆形

      Returns void

      Example

      const drawObj = new Draw({ cesiumGlobal: Cesium, containerId: 'cesiumContainer' })
      drawObj.drawCircleGraphics({
        callback: ({ center, radius }, entity) => {
          // center 为圆心（Cartesian3），radius 为半径（米）
          console.log(center, radius, entity)
        }
      })
